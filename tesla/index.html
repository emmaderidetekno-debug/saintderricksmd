What it does

Every command group is a plugin, loaded from the files repo when the bot starts.

group

Group management

Add, remove, promote and demote, anti-link, anti-tag, welcome messages and anti-demote / anti-promote guards.

ai

AI chat

Ask questions, analyse images and chat in DMs. Replies follow your language and mood, with memory of the conversation.

downloads

Downloaders

Fetch music, video and media from popular platforms straight into the chat.

media

Media tools

Stickers, image and audio conversion, background removal and effects.

settings

Live settings

Antidelete, auto view and like status, anticall, presence and more, switched on or off from chat.

owner

Owner and sudo

Add sudo users with the same privileges as the owner, broadcast, block, restart and update.

tools

Everyday tools

Weather, lookups, text tools, QR, translators and quick utilities.

sports

Sports and fun

Football scores and standings, games, jokes and logos.

coding

Coding

Run C, C++, JavaScript and Python snippets, create code images and obfuscate scripts.

Get it running

Three steps. You need a Heroku account and a WhatsApp number.

  1. Pair your numberOpen the pairing site, enter your WhatsApp number and copy the session ID it gives you.
  2. DeployPress Deploy on Heroku, paste the session ID in SESSION and set DEV to your number.
  3. Say helloWhen the status above reads Connected, send .menu to the bot number.

Config vars

Set these under Settings → Config Vars. Only SESSION is required.

SESSIONThe session ID from the pairing site. Required.
DEVOwner number, digits only with country code. Separate several with commas.
DATABASE_URLPostgres connection for settings. Heroku Postgres sets this for you.
TIMEZONETime zone used in reports such as antidelete, for example Africa/Nairobi.
MENU_TYPEMenu style the bot sends.
STICKER_PACKNAMEPack name written into stickers. STICKER_AUTHOR sets the author.
APP_NAMEYour Heroku app name. Used with HEROKU_API by restart and variable commands.
HEROKU_APIHeroku API key for the owner commands that change vars or restart the app.
GPTDM_MODELOptional. Model used by AI chat in DMs. GPTDM_MEMORY and GPTDM_MEMORY_HOURS set how much it remembers.
MAX_FAILED_CLOSESOptional. How many failed reconnects before the bot exits and Heroku restarts it. Default 8.
CORE_BRANCHOptional. Branch or tag of the files repo to load. Pin it to freeze a known good version.

Questions

The status says reconnecting or failed

Check the Heroku logs. A message about a logged out device means you need to pair again. A message about a replaced connection means another copy is running on the same session.

Can two apps share one session?

No. WhatsApp allows one connection per session, so two copies keep kicking each other off and can end in a logout.

How do I update the bot?

Plugins and core files are downloaded from the files repo each time the app starts, so a restart is enough. The owner command update also redeploys.

Is this affiliated with WhatsApp?

No. St. Derricks MD is an independent project. Use it responsibly and follow WhatsApp's terms.
